# КБЖУ Дневник

Мобильное веб-приложение (PWA) для учёта питания: фотографируете еду — нейросеть **Gemini 2.5 Flash через OpenRouter** считает калории, белки, жиры и углеводы. Ставится на рабочий стол как обычное приложение.

## Возможности

**Распознавание**
- Фото или текстовое описание блюда
- Нейросеть разбирает кадр на компоненты (гарнир, мясо, соус, масло) и суммирует их — видно, из чего сложился итог
- Учитывает способ приготовления: жарка, панировка, соусы, сахар в напитках
- Показывает уверенность модели и её допущения
- **Уточнение словами**: «это было на гриле, масла почти не было» → пересчёт с учётом поправки

**Дневник**
- Просто список еды за день — без деления на завтрак/обед/ужин
- Быстрое добавление из избранного и из недавних блюд (порция ×0,5 / ×1 / ×1,5 / ×2)
- Копирование записи с прошлого дня на сегодня, дублирование
- Редактирование любой записи, удаление с отменой
- Навигация по дням: свайп, стрелки на клавиатуре, календарь
- Избранное: сохранение из записи, редактирование порции и КБЖУ, удаление

**Автоматизация расчётов**
- Меняете вес порции — КБЖУ пересчитывается пропорционально
- Меняете белки/жиры/углеводы — калории пересчитываются по 4/9/4
- Меняете калории — БЖУ масштабируются с сохранением пропорций

**Ещё**
- Статистика: калории за 7 или 30 дней, средние КБЖУ
- Вес: запись и удаление прямо в статистике, график динамики
- Дневная норма КБЖУ — вводится вручную
- Тёмная и светлая темы (по системе или вручную)
- Резервная копия в JSON: экспорт и импорт
- Полностью офлайн после первого запуска

## API-ключ

Запросы идут напрямую в OpenRouter, без промежуточного сервера. Ключ хранится только в localStorage браузера.

1. Регистрация на [openrouter.ai](https://openrouter.ai) → **Keys** → **Create Key**
2. Приложение → **Настройки** → **Нейросеть** → вставить ключ → **Проверить ключ**
3. Модель по умолчанию — `google/gemini-2.5-flash`, можно заменить в том же блоке

## Установка на телефон

1. Открыть адрес в Chrome (Android) или Safari (iOS)
2. Меню → **«Добавить на главный экран»**
3. Иконка появится на рабочем столе

## Локальный запуск

```bash
python -m http.server 8080
```

Открыть `http://localhost:8080`.

## Структура

```
kbzy/
├── index.html              # Разметка всех экранов
├── css/style.css           # Дизайн-система: токены, темы, компоненты
├── js/
│   ├── icons.js            # Иконки Lucide — инлайн SVG, без сети
│   ├── db.js               # IndexedDB (записи, избранное, вес) + настройки
│   ├── api.js              # OpenRouter: промпт, разбор ответа, сжатие фото
│   └── app.js              # Вся логика интерфейса
├── sw.js                   # Service worker, офлайн-кеш
├── manifest.webmanifest    # Манифест PWA
├── icons/                  # Иконки приложения
└── scripts/
    ├── generate_icons.py   # Перегенерация иконок (Pillow)
    └── verify.py           # Проверка структуры проекта
```

## Технологии

- **Vanilla JS** без сборщика и зависимостей — только статические файлы
- **Lucide** (ISC) — иконки вшиты как SVG-пути в `js/icons.js`, ничего не грузится из CDN
- **IndexedDB** — записи, избранное, вес; **localStorage** — настройки и ключ
- **CSS-переменные** — две темы без дублирования стилей

## Проверка перед пушем

```bash
node --check js/app.js
python scripts/verify.py
```

`verify.py` проверяет структуру, манифест, размеры иконок, соответствие `id` в разметке и коде, наличие обработчиков для кнопок `data-action` и отсутствие ключей в исходниках.

### E2E-тесты в браузере

`scripts/e2e-tests.js` — 147 проверок: логика расчётов, CRUD, избранное, даты, статистика, вес, настройки, экспорт/импорт, XSS, доступность, переполнение вёрстки, ошибки сети, производительность.

```bash
python -m http.server 8099 --bind 127.0.0.1

playwright-cli open "http://127.0.0.1:8099/index.html"
playwright-cli eval "async () => {
  const src = await (await fetch('/scripts/e2e-tests.js')).text();
  (0, eval)(src);
  const a = await window.__runTests();
  const b = await window.__runExtraTests();
  return JSON.stringify({ main: a.passed + '/' + a.total, extra: b.passed + '/' + b.total, fails: [...a.failed, ...b.failed] });
}"
```
