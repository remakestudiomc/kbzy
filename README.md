# 🍽️ КБЖУ Дневник — счётчик калорий с нейросетью

Мобильное веб-приложение (PWA): фотографируете еду — нейросеть **Google Gemini 2.5 Flash (через OpenRouter)** считает калории, белки, жиры и углеводы. Устанавливается на рабочий стол как обычное приложение с иконкой.

## ✨ Возможности

- 📷 **Фото + нейросеть**: сфотографируйте блюдо (или выберите из галереи), нейросеть определит КБЖУ за 5–15 секунд
- ✍️ **Расчёт по описанию**: нет фото? Просто опишите блюдо словами — нейросеть посчитает КБЖУ
- ✏️ **Редактирование**: результат можно исправить перед сохранением
- 💾 **Дневник**: записи хранятся локально на устройстве, привязаны к датам
- ⚖️ **Контроль веса**: записывайте вес и отслеживайте динамику
- 📊 **Прогресс дня**: калории, белки, жиры, углеводы — текущее значение / дневная норма
- ⚙️ **Нормы КБЖУ**: задайте свои дневные цели
- 📅 **Навигация по дням**: просматривайте прошлые дни, добавляйте записи задним числом
- 📴 **Офлайн-режим**: приложение и записи работают без интернета (для анализа фото нужен интернет)

## 🔑 Настройка нейросети (API-ключ OpenRouter)

Приложение обращается к нейросети **напрямую через OpenRouter** — без промежуточных серверов. Ключ хранится **только в localStorage вашего браузера** и отправляется исключительно в OpenRouter.

1. Зарегистрируйтесь на **https://openrouter.ai** (бесплатно)
2. Перейдите в **Keys** → **Create Key**
3. Скопируйте ключ (начинается с `sk-or-v1-...`)
4. Откройте приложение → ⚙️ **Настройки** → вставьте ключ в поле **API-ключ OpenRouter** → **Сохранить** (рядом с полем есть кнопка **«Проверить ключ»** — она сразу покажет, верный ли ключ и доступен ли OpenRouter из вашей сети)

> 💡 Gemini 2.5 Flash доступна на OpenRouter, у новых аккаунтов есть пробный бесплатный лимит, дальше модель стоит копейки. Ключ никогда не публикуется в коде сайта и не виден другим посетителям.

## 🚀 Установка на телефон (Android)

1. **Разместите приложение на сервере с HTTPS** (бесплатно: GitHub Pages, Netlify, Vercel)
2. Откройте адрес в **Chrome** на Android
3. Нажмите **⋮** (меню) → **«Добавить на главный экран»** или **«Установить приложение»**
4. Иконка появится на рабочем столе — запускайте как обычное приложение

### Как запустить локально (для теста)

```bash
python -m http.server 8080
```

Затем откройте `http://localhost:8080` в браузере.

## 📱 Как пользоваться

1. **Откройте приложение** с рабочего стола
2. Нажмите **＋** (большая оранжевая кнопка внизу) — «Добавить приём пищи»

**Вариант А — по фото:**
3. **📷 Сделайте фото** блюда целиком (или 🖼 выберите из галереи)
4. При желании добавьте **описание** (например: «овсянка с бананом и орехами») — это повысит точность

**Вариант Б — по описанию (без фото):**
3. Введите в поле **«Описание блюда»** что вы ели (например: «гречка с курицей и овощами, 250 г»)

5. Нажмите **✨ Рассчитать КБЖУ** — нейросеть определит блюдо и посчитает калории, белки, жиры, углеводы
6. **Проверьте результат** — все значения можно отредактировать (название, вес, калории, БЖУ)
7. Нажмите **✓ Сохранить в дневник** — запись появится в дневнике, итоги дня обновятся

Если результат не понравился — нажмите **🗑 Удалить** и сделайте фото заново.

### ⚖️ Вес

В **⚙️ Настройках** есть блок **«Мой вес»**: введите вес → **Записать**. Последняя запись считается текущей, под ней — изменение относительно предыдущей. Список записей удаляется кнопкой ✕. Вес хранится локально на устройстве.

## 🛠 Технологии

- **PWA** (Progressive Web App) — устанавливается на Android без Play Маркета
- **OpenRouter + Google Gemini 2.5 Flash** — распознавание еды по фото прямыми запросами из браузера (без прокси-сервера)
- **IndexedDB + localStorage** — локальное хранение записей, веса и настроек (работает офлайн)
- **Vanilla JS** — без фреймворков

## ⚠️ Важно знать

- Точность нейросети хорошая, но **не 100%** — всегда проверяйте результат и при необходимости корректируйте
- Для максимальной точности фотографируйте блюдо **целиком сверху**, рядом с предметом известного размера (вилка, ложка)
- Данные (записи, фото, вес, ключ) хранятся **только на вашем устройстве** и никуда не отправляются — кроме запроса КБЖУ в OpenRouter по вашему ключу
- Для анализа фото нужны интернет и введённый API-ключ
- Для перегенерации иконок: `pip install Pillow && python scripts/generate_icons.py`
- Проверка проекта: `python scripts/verify.py`
