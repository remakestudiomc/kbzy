# 🍽️ КБЖУ Дневник — счётчик калорий с нейросетью

Мобильное веб-приложение (PWA) для Android: фотографируете еду — бесплатная нейросеть **Google Gemini** считает калории, белки, жиры и углеводы. Устанавливается на рабочий стол как обычное приложение с иконкой.

## ✨ Возможности

- 📷 **Фото + нейросеть**: сфотографируйте блюдо (или выберите из галереи), нейросеть определит КБЖУ за 5–15 секунд
- ✍️ **Расчёт по описанию**: нет фото? Просто опишите блюдо словами — нейросеть посчитает КБЖУ
- ✏️ **Редактирование**: результат можно исправить перед сохранением
- 💾 **Дневник**: записи хранятся локально на телефоне, привязаны к датам
- 📊 **Прогресс дня**: калории, белки, жиры, углеводы — текущее значение / дневная норма, прогресс-бары
- ⚙️ **Нормы КБЖУ**: задайте свои дневные цели (калории, белки, жиры, углеводы)
- 📅 **Навигация по дням**: просматривайте прошлые дни, добавляйте записи задним числом
- 📴 **Офлайн-режим**: приложение и записи работают без интернета (для анализа фото нужен интернет)
- 🆓 **Бесплатно**: Gemini Flash бесплатен (~1500 запросов в день — для 5–10 фото в день с огромным запасом)

## 🚀 Установка на телефон (Android)

1. **Разместите приложение на сервере с HTTPS** (или запустите локально — см. ниже)
2. Откройте адрес в **Chrome** на Android
3. Нажмите **⋮** (меню) → **«Добавить на главный экран»** или **«Установить приложение»**
4. Иконка появится на рабочем столе — запускайте как обычное приложение

### Как запустить локально (для теста)

```bash
# Из папки проекта запустите локальный сервер:
python -m http.server 8080
```

Затем откройте `http://localhost:8080` в браузере. Для теста на реальном телефоне понадобится HTTPS-хостинг (можно бесплатный: GitHub Pages, Netlify, Vercel).

## 🔑 Настройка нейросети (бесплатный ключ Gemini)

Ядро — **Google Gemini Flash**, бесплатная модель, которая умеет анализировать изображения.

1. Перейдите на сайт: **https://aistudio.google.com/apikey**
2. Войдите с аккаунтом Google
3. Нажмите **«Create API key»**
4. Скопируйте ключ (начинается с `AIza...`) — он бесплатный
5. Откройте приложение → ⚙️ **Настройки** → вставьте ключ в поле «API-ключ Google Gemini» → **Сохранить**

> 💡 Бесплатный тариф Gemini Flash — **~1500 запросов в день**. При 5–10 фото в день этого хватит на месяцы. Ключ хранится только в вашем приложении на телефоне.

## 📱 Как пользоваться

1. **Откройте приложение** с рабочего стола
2. Нажмите **＋** (большая оранжевая кнопка внизу) — «Добавить приём пищи»

**Вариант А — по фото:**
3. **📷 Сделайте фото** блюда целиком (или 🖼 выберите из галереи)
4. При желании добавьте **описание** (например: «овсянка с бананом и орехами») — это повысит точность

**Вариант Б — по описанию (без фото):**
3. Введите в поле **«Описание блюда»** что вы ели (например: «гречка с курицей и овощами, 250 г»)
4. Описание может полностью заменить фото

5. Нажмите **✨ Рассчитать КБЖУ** — нейросеть определит блюдо и посчитает калории, белки, жиры, углеводы
6. **Проверьте результат** — все значения можно отредактировать (название, вес, калории, БЖУ)
7. Нажмите **✓ Сохранить в дневник** — запись появится в дневнике, итоги дня обновятся

Если результат не понравился — нажмите **🗑 Удалить** и сделайте фото заново.

## 🛠 Технологии

- **PWA** (Progressive Web App) — устанавливается на Android без Play Маркета
- **Google Gemini API** — бесплатная нейросеть для распознавания еды по фото (модели: Gemini Flash Latest, 2.5 Flash, 2.5 Flash Lite — приложение автоматически перебирает их и выбирает рабочую)
- **IndexedDB** — локальное хранение записей и фотографий (работает офлайн)
- **Vanilla JS** — без фреймворков, быстро и легковесно

## ⚠️ Важно знать

- Точность нейросети хорошая, но **не 100%** — всегда проверяйте результат и при необходимости корректируйте
- Для максимальной точности фотографируйте блюдо **целиком сверху**, рядом с предметом известного размера (вилка, ложка)
- Данные (записи с фото) хранятся **только на вашем устройстве** — никуда не отправляются
- Для анализа фото нужен интернет
- Для перегенерации иконок: `pip install Pillow && python scripts/generate_icons.py`
