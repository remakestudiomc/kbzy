# ☁️ Безопасный ключ через Cloudflare Worker

Приложение вызывает нейросеть **через Cloudflare Worker**. Сам ключ Gemini хранится **только в настройках Cloudflare** — в коде приложения его нет.

## ⏱ Время: 5 минут, бесплатно

## 📋 Шаг 1: Зарегистрируйтесь на Cloudflare

1. Откройте **https://dash.cloudflare.com/sign-up**
2. Укажите email и пароль (бесплатный тариф 100 000 запросов/день)

## 📋 Шаг 2: Создайте Worker

1. В панели слева нажмите **Workers & Pages**
2. Нажмите **Create** → **Create Worker**
3. Имя: `kbzy-proxy`
4. Нажмите **Deploy** (создастся пустой worker)

## 📋 Шаг 3: Вставьте код

1. Нажмите **Edit Code**
2. **Удалите код по умолчанию полностью**
3. Вставьте содержимое файла **`worker/worker.js`** из этого проекта
4. Нажмите **Deploy**

## 📋 Шаг 4: Добавьте ключ в секреты

1. На странице Worker перейдите в **Settings** → **Variables**
2. В секции **Environment Variables** нажмите **Add**
3. Имя переменной: `GEMINI_API_KEY`
4. Значение: **ваш ключ Gemini** (нач. на `AIza...` или `AQ...`)
5. Нажмите **Encrypt** — так ключ будет скрыт
6. Нажмите **Save**

## 📋 Шаг 5: Скопируйте URL Worker

1. Вернитесь на главную страницу Worker (вкладка **Overview**)
2. Скопируйте ссылку вида: `https://kbzy-proxy.ВАШ_АККАУНТ.workers.dev`

## 📋 Шаг 6: Вставьте URL в приложение

1. Откройте приложение → ⚙️ **Настройки**
2. В поле **«URL облачного Worker»** вставьте ссылку
3. Нажмите **Сохранить**

## ✅ Готово!

Теперь нейросеть работает, а ключ спрятан на Cloudflare.

## ⚠️ ВАЖНО: если Worker уже развёрнут ранее

Если вы разворачивали Worker **до этой версии** и получаете ошибку
«Не удалось подключиться к облачному Worker» — проблема в CORS-preflight
(браузер блокирует запрос из-за неправильного ответа на OPTIONS).

Чтобы исправить, **обновите код воркера на Cloudflare**:

1. Откройте **https://dash.cloudflare.com** → Workers & Pages → `kbzy-proxy`
2. Нажмите **Edit Code**
3. **Удалите весь старый код**, вставьте **текущее** содержимое файла **`worker/worker.js`** из проекта
4. Нажмите **Deploy**
5. Затем проверьте по разделу «Проверка» ниже

## 🔍 Как проверить, что всё работает

Откройте браузер (Chrome/Edge) → **F12** → вкладка **Console** → вставьте команду:

```js
fetch('ВАШ_URL_ВОРКЕРА', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ image: '', description: 'гречка с курицей' })
}).then(r => r.json()).then(d => console.log('Worker OK:', d)).catch(e => console.error('Worker ERROR:', e));
```

- Если в консоли появится `Worker OK: { ... }` — всё работает, попробуйте снова записать в дневник.
- Если `Worker ERROR` или `TypeError: Failed to fetch` — URL воркера недоступен или CORS всё ещё не починен (повторите обновление кода выше).
- Если ответ содержит `API key not valid` / `403` — ключ `GEMINI_API_KEY` на Cloudflare неверный или отозван, обновите его в Settings → Variables.

## 🔒 Почему это безопасно

| | Ключ в коде (старый) | Ключ на Cloudflare (новый) |
|---|---|---|
| Виден кому-либо? | Да, все видят | Нет, только вы |
| Можно украсть? | Да | Нет (зашифрован) |
| Приватный репозиторий? | Не нужен | Не нужен |
| Смена ключа | Правка кода + push | 1 минута на Cloudflare |

## 🔄 Если ключ нужно заменить

1. Cloudflare → Worker → Settings → Variables
2. Измените значение `GEMINI_API_KEY`
3. Нажмите Save
4. Готово — код приложения менять не нужно
